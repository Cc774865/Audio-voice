# 口误与发音

## 时间戳规则

| 类型 | 判定 |
|---|---|
| 重复 | 相邻两个相同实词 |
| 卡顿词 | 「那个那个」「就是就是」 |
| 语气词 | 嗯 / 呃 / 额 / 唔 / 哎 / 诶 / 欸 |
| 残句 | 全文不以 。？！ 收束，或某句去掉逗号后只剩 0–1 个字 |
| 句中停顿 | 两个实词空隙 ≥ 350ms |
| 逗号停顿 | ，、； 后停顿须大于 120ms，且不超过 500ms |
| 句末过长 | 。？！ 时长 ≥ 800ms |
| 吞音 | 非语气助词单字 < 70ms |
| 拖音 | 非标点单字超过 550ms |
| 问句语调弱 | 有问号但问号时长 < 80ms |

## 桶 A：发音错误（FunASR）

对照原稿（同名 json 拼出的文本，或 txt/md 正文）与本地 FunASR 转写：

- CER ≥ 8%
- 原稿里的拉丁字母/英文词在识别结果中缺失（如 D → 既）
- 课件词缺失：函数、变量、坐标、图像、定义域等
- 或一期 `gate=fail`（残句、多处重复）

错误句**全部列出**，**不计入** 6 个典型例；每条都要写入不合格记忆库（见 [memory.md](memory.md)）。

## 桶 B / C

- B：未进 A，但有停顿/拖音/吞音/语速出带，或不流畅分偏低
- C：未进 A/B，且单句综合分 < 76

## 门槛

残句或多于 1 处连续重复 → `gate=fail`，该句分数封顶 60。

txt/md 正确稿没有出品时间戳：逗号是否过短不按 json 规则卡，句中空隙/拖音/吞音用识别时间戳估计。
