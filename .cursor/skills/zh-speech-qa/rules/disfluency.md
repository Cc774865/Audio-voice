# 一期口误规则（无 ASR）

只扫时间戳 JSON 拼出的口播稿 + 字级时长。不要假装检出了错读。

## 自动检出

| 类型 | 判定 |
|---|---|
| 重复 | 相邻两个相同实词 |
| 卡顿词 | 「那个那个」「就是就是」 |
| 语气词 | 嗯 / 呃 / 额 / 唔 / 哎 / 诶 / 欸 |
| 残句 | 全文不以 。？！ 收束，或某句去掉逗号后只剩 0–1 个字 |
| 句中停顿 | 两个实词空隙 ≥ 350ms |
| 逗号过长 | ，、； 时长 ≥ 400ms |
| 句末过长 | 。？！ 时长 ≥ 800ms |
| 吞音 | 非语气助词单字 < 70ms |
| 拖音 | 非标点单字 ≥ 450ms |
| 问句语调弱 | 有问号但问号时长 < 80ms |

## 一期不检（报告里写未测）

- 错字、错读、多音字
- 声调用错
- 与原稿 CER
- 「像不像人」

## 门槛

出现残句，或多于 1 处连续重复 → `gate=fail`，分数封顶 60。
