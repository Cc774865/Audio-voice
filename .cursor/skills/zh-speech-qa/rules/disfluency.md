# 口误与发音

## 时间戳规则

| 类型 | 判定 |
|---|---|
| 重复 | 相邻两个相同实词 |
| 卡顿词 | 「那个那个」「就是就是」 |
| 语气词 | 嗯 / 呃 / 额 / 唔 / 哎 / 诶 / 欸 |
| 残句 | 全文不以 。？！ 收束，或某句去掉逗号后只剩 0–1 个字 |
| 句中停顿 | 两个实词空隙 ≥ 400ms |
| 逗号停顿 | ，、； 后停顿须大于 140ms，且不超过 500ms |
| 句末过长 | 。？！ 时长 ≥ 800ms |
| 吞音 | 非语气助词单字 < 70ms |
| 拖音 | 非标点单字超过 550ms |
| 标点连读 | 句读标点（，。；？！）两侧实词空隙 ≤ 60ms，且 ASR 把前后字直接粘在一起。顿号列举不判。进桶 A |

## 桶 A：发音错误（FunASR）

对照原稿（同名 json 拼出的文本，或 txt/md 正文）与本地 FunASR 转写：

- CER ≥ 8%
- 原稿里的拉丁字母/英文词在识别结果中缺失（如 D → 既）
- 课件词缺失：函数、变量、坐标、图像、定义域等
- 标点连读：逗号/句号等没有造成停顿（两侧实词空隙 ≤ 60ms）且 ASR 把前后字粘在一起
- 或一期 `gate=fail`（残句、多处重复）

错误句**全部列出**，**不计入** 6 例；每条都要写入不合格记忆库（见 [memory.md](memory.md)）。

多音字不进本桶，见 [polyphone.md](polyphone.md)。

## 桶 P：多音字（待审）

规则单独立在 [polyphone.md](polyphone.md)。全部列出，不占 6 例，不扣整课错误惩罚，不自动入库。

## 桶 B / C

- B：未进 A/P，但有停顿/拖音/吞音/语速出带，或不流畅分偏低
- C：未进 A/P/B，且单句综合分 < 76

## 门槛

残句或多于 1 处连续重复 → `gate=fail`，该句分数封顶 60。

这些毫秒值和 CER 8% 可通过 `calibrate.py` 建议微调，确认后才改脚本；不要重训 FunASR。

txt/md 正确稿没有出品时间戳：逗号是否过短不按 json 规则卡，句中空隙/拖音/吞音用识别时间戳估计。
