# 多音字（桶 P）

多音字单独成桶，不和 CER / 缺词 / gate 混进桶 A。音高估计噪声大，所以 **P 是待审，不是自动不合格**。

## 和别的桶的关系

一条句子只进最高优先级：

1. **A** CER≥8%、缺关键词、gate=fail
2. **P** 高证据多音字不符
3. **B** 不流畅
4. **C** 单句分 < 76
5. **ok**

桶 P：

- 全部列出，不占 6 例
- **不计入**整课错误句惩罚
- **不自动**写入 fail 库
- 单句 accuracy 每处 −3（轻于缺词的 −6）
- Agent 在「逻辑」里判断像不像误报；用户说要标再入库

## 先定该读什么（语境）

| 情况 | 预期 |
|---|---|
| 知识库组词命中 | 用该读音（地质 → `dì`） |
| 结构助词「的」 | 永远 `de`，不听音高 |
| 「目的」「标的」 | `dì` |
| 「的士」 | `dí` |
| 「地」+ 名词组词 | `dì` |
| 「地」后面跟状态/动词（一个一个地数） | `de` |
| 「得」在得到/觉得等词里 | `dé` |
| 「得」作补语 | `de` |

组词表：[polyphones.json](polyphones.json)，由《最全多音字总汇》编译：

```bash
.\.venv\Scripts\python.exe .cursor/skills/zh-speech-qa/scripts/compile_polyphones.py
```

## 什么情况下不进 P

- 结构助词「的」：轻声下滑很容易看成去声
- 疑问「哪」（哪些 / 哪个 / 哪里 / 哪年等）：允许 `nǎ` 和 `něi`，不把阳平误配成「哪吒」
- 轻声与三声视为同族
- 同调不同声母（行 xíng/háng）不强判
- 时间戳不可靠、裁切后过短、或声调置信度 < 0.75

## 进 P 必须同时满足

1. 语境已经给出**唯一**预期读音
2. 听测结果是另一个**成词**读音，不是噪声
3. 声调置信度 ≥ 0.75（去声要明显下降，阳平要明显上升）
4. 「地」「得」从 `de` 改判 `dì`：裁掉前后字后时长 ≥ 200ms

「一个一个地数」读成 `dì` 会进 P。「变化前的数量」里的「的」不会。

FunASR 只出汉字，分不出「地」读 de 还是 dì，所以这一桶只靠时间戳裁音频估调。
